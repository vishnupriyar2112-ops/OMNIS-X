# OMNIS-X API

Interactive documentation is available at `/docs`.

## Authentication

`POST /api/auth/login`

## Core endpoints

- `GET /api/dashboard`
- `GET /api/twin`
- `GET /api/dependency`
- `GET /api/conflicts`
- `GET /api/simulations/scenarios`
- `POST /api/simulations/run`
- `GET /api/recovery?scenario=electricity`
- `GET /api/incidents`
- `POST /api/incidents`
- `GET /api/incidents/export`
