# Demo Guide

1. Open the login page and use the demo button.
2. Review the command-centre health and resource cards.
3. Open the Digital Twin to view campus entities.
4. Open Dependency Network to inspect provider/dependent links.
5. Open Conflict Detection to view constraint violations.
6. Run a failure scenario in Failure Simulation.
7. Open Recovery Centre to compare candidate plans.
8. Open Incident History and export the CSV report.
